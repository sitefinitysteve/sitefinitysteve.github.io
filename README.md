# sitefinitysteve.github.io

Public web pages for my mobile apps, served by GitHub Pages at https://sitefinitysteve.github.io/.

The app stores and Google AdMob need these pages to be public. The apps' source code lives elsewhere and is not in this repo.

| Page | URL |
| --- | --- |
| Scorecerer | https://sitefinitysteve.github.io/scorecerer/ |
| Scorecerer privacy policy | https://sitefinitysteve.github.io/scorecerer/privacy/ |
| app-ads.txt | https://sitefinitysteve.github.io/app-ads.txt |

`app-ads.txt` must stay at the root of this domain. AdMob looks for it there to confirm which ad accounts may sell ads in these apps. Every line in it is public information.
